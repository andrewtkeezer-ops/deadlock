Get your matches tracked

Valve doesn't publish a list of matches. A tracker needs each match's ID plus a one-time key (a "salt") that only your Steam client downloads. So every friend runs a tiny background tool once; after that, every game you play shows up here automatically, and it backfills your old games too.

Step 1 — install the ingest tool (Windows)

Open PowerShell (Start → type "PowerShell") and paste:

irm https://raw.githubusercontent.com/deadlock-api/deadlock-api-ingest/master/install-windows.ps1 | iex

It installs to your user folder, starts on login, and shows a small window listing each match it sends (you can close it; it keeps running). Admin rights are only asked for to create the auto-start task. It uploads only match IDs, salts and your public Steam account ID — never your Steam login. Source: github.com/deadlock-api/deadlock-api-ingest (MIT, written in Rust).

Linux / Steam Deck
curl -fsSL https://raw.githubusercontent.com/deadlock-api/deadlock-api-ingest/master/install-linux.sh | bash
Prefer it to only run while the game is open?

Skip the installer, download deadlock-api-ingest-windows-latest.exe from the releases page, and set Deadlock's Steam launch option to:

"C:\Users\YOUR_USER\AppData\Local\deadlock-api-ingest\deadlock-api-ingest.exe" -- %command%

Step 2 — sign in through Steam

This just tells us which Steam account is yours. We never see your password; Steam only hands back your public ID. Your matches import right away.
